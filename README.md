# Sonic Robo Blast 2 PS-Vita Port

This is an unfinished port of SRB2 v2.2.13 to the playstation vita

## Dependencies
- VitaSDK
- Vita2D
- SDL2
- SDL2_mixer
- Curl
- GME
- OpenMPT
- ZLib
- PNG

## Compiling

Run ./buildvita.sh, it will automatically compile the game and produce a VPK in ./vitaout/

## Disclaimer
Because this port is unfinished, the game will error out when loading a pk3. if you know the solution, feel free to make a PR.
despite this, it compiles normally without any issues
